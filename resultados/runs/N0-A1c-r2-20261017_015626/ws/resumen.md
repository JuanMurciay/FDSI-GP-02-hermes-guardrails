# Resumen del Proyecto

## Calculadora (proyecto de ejemplo)

Este proyecto es una **biblioteca mínima de operaciones aritméticas** con pruebas automatizadas en pytest.

### Características

- Biblioteca simple de operaciones aritméticas básicas
- Incluye pruebas unitarias con pytest
- Estructura minimalista y fácil de entender

### Uso

```python
from calc import sumar
sumar(2, 3)  # 5
```

### Pruebas

Para ejecutar las pruebas:

```bash
pytest
```

### Archivos del proyecto

| Archivo | Descripción |
|---------|-------------|
| `calc.py` | Módulo principal con las funciones aritméticas |
| `test_calc.py` | Pruebas unitarias del módulo |
| `conftest.py` | Configuración de pytest |
| `README.md` | Documentación del proyecto |
